# XeroHoloGram

> **Ultra-Low-Latency 3D Holographic AI Agent Harness & Universal Rigged-Character Engine**  
> Engineered for Physical Pepper's Ghost Optical Stages (180° flat display + 45° Pythagorean beam splitter) and Standard 3D Web Viewports.

## Core Capabilities
- **60 FPS Hologram Engine**: Built on Three.js & WebGL 2.0 with custom holographic Fresnel rim shaders, chromatic aberration, scanlines, and zero-alpha pure-black stage occlusion.
- **Pepper's Ghost Optical Calibration**: Real-time horizontal/vertical axis inversion, 45° Pythagorean FOV perspective correction, and trapezoidal keystone projective homography.
- **Universal Rig Engine & Bone Studio**: Drag-and-drop `.glb` / `.gltf` / `.vrm` character models with automated naming heuristics (Mixamo, VRM, Unreal Engine, Rigify) mapping onto a canonical 55-bone humanoid skeleton.
- **60Hz SO(3) Critically Damped Kinematics**: Gimbal-lock-free quaternion spring-damper dynamics, look-at gaze solver with anatomical cervical spine limits, micro-saccadic eye tracking, and harmonic breathing.
- **Dual-Mode Viseme Lip-Sync**: Real-time Web Audio FFT spectral energy formant analyzer (F1/F2/F3) mapping to 15 Preston Blair/Oculus viseme targets + timestamp-guided phoneme alignment.
- **Ultrafast Async Multiplexer Daemon**: Python FastAPI + uvloop full-duplex WebSocket streaming with sub-50ms barge-in interruption and dual parallel generation streams (Stream A: Acoustics; Stream B: D3 Kinematic Gestures).
- **Universal TTS Adapter Pipeline**: Out-of-the-box support for Edge-TTS, Kokoro-82M, ElevenLabs, Cartesia Sonic, OpenAI TTS, and local Piper.
